# 在正文中，直接找到内容

按 **⌘F** 打开查找栏，阅读界面会保持在预览模式。输入关键词后，所有匹配会以黄色标出，当前结果使用橙色强调。

查找栏显示当前位置和匹配总数。点击上 / 下箭头，或在输入框按 **Shift-Return / Return**，可以循环跳转。也可以使用 **⇧⌘G / ⌘G**。

## 跨越行内格式

本地**文件**阅读，这句话中的粗体不会把一个搜索短语切断。

这里还有一处普通文字：本地文件阅读。

点击[跳到后面的阅读记录](#阅读记录)，可以验证链接在高亮状态下仍然正常工作。

## 不同文字与符号

中文可以直接搜索，emoji 🙂 也可以。英文默认不区分大小写：Hello、HELLO 和 hello 会一起匹配。

搜索词中的特殊符号按普通文字处理：`a+b? [x]` 不会被当作正则表达式。

## 表格和代码

| 位置 | 备注 |
| :--- | :--- |
| 本地文件阅读 | 表格中的文字同样可查找 |
| 中文与 English | 仍然保留原来的列对齐 |

```swift
struct ReadingSpace {
    let title = "本地文件阅读"
    let staysLocal = true
}
```

可见的代码也能搜索，代码语法高亮和复制按钮会保留原样。

## 公式和图表

公式 $E=mc^2$ 的可见文字可以检索，隐藏的辅助 MathML 不会重复计数。

```mermaid
flowchart LR
    A[ReadingSpace] --> B[FindText]
    B --> C[KeepReading]
```

图表中可见的文字也能定位；折叠起来的图表源码不会混入正文结果。展开源码后，其中的可见文字才会加入查找。

## 阅读记录

这是另一处本地文件阅读。切换主题时，当前匹配和阅读位置会继续保留。

搜索不会改写文档、链接或公式，也不会覆盖你选择的文本。你可以一边查找，一边继续阅读。

## 清空与关闭

更换一个正文中没有的关键词，查找栏会显示「无匹配」。清空输入或在查找栏按 Esc 关闭查找，会移除所有高亮。

需要查看 Markdown 原文时，仍可手动切换到源码模式；查找词会跟随模式切换。
