# 从阅读，到修改

Markdown、SVG、JSON、CSV / TSV 和常见代码都可以切到「源码」编辑；普通文本直接编辑。修改会留在当前标签，切换文件或预览不会丢失。

## 手动保存

把这一句改成自己的话，观察标签上的小圆点与「未保存」提示，再按 **⌘S**。默认手动保存；也可以在「设置 → 编辑模式」开启自动保存，停止输入约 1 秒后写入磁盘。

源码编辑支持 **⌘Z** 撤销、**⇧⌘Z** 重做，以及系统的剪切、复制、粘贴。切换预览或其他标签后，返回源码还能继续撤销。

## 预览跟随修改

把下面列表的内容改掉，然后切换到预览：

- 一份文档
- 一组数据
- 一段代码

再打开 [项目.json](项目.json) 或 [阅读清单.csv](阅读清单.csv)，在源码中编辑后查看结构化预览。JSON / CSV 格式不完整时会显示解析错误，源码仍然可以编辑和保存。

## 解释一个源码值

打开[项目.json](项目.json)，切到源码，在 `inspectionExamples` 中尝试以下选区：

| 选中的值 | 解释方式 | 可以观察什么 |
| --- | --- | --- |
| `"#3A609580"` | 颜色 | 半透明蓝色，修改后保留引号 |
| `1794268800` | 时间戳 · 秒 | 2026-11-10T00:00:00.000Z |
| `1794268800123` | 时间戳 · 毫秒 | 2026-11-10T00:00:00.123Z |
| `1572864` | 字节大小 | 1536 KiB / 1.5 MiB；纯数字可手动切换解释方式 |
| `"1.5 MiB"` | 字节大小 | 二进制单位与十进制单位的区别 |
| `escapedText` 后的完整字符串值 | 转义字符串 | 换行、制表符和中文 / emoji 的解码结果 |

选中后点击源码工具区的「解释所选值」。面板里的解释方式、时间单位和时区都可更正；点击「替换选中内容」才更新草稿。试着调整颜色，然后用 ⌘Z 撤销。自动保存是否写入磁盘沿用当前设置。

如果面板打开后源码或选区发生变化，替换会被拒绝，请重新选择。解释过程只在本机处理选中的一个值。

## 长行保持原文

源码随窗口宽度软换行，不会改变文件中的实际换行。代码预览保留原有长行，宽度不够时可以横向滚动。切换源码与预览时，草稿、选区和撤销记录继续保留。

## 关闭与冲突

修改后关闭标签、关闭窗口、重新载入或退出应用，会先询问保存、不保存或取消。取消会保留编辑；保存失败也会保留编辑。

如果用其他编辑器修改了同一份文件，回到 Luma 或切换标签时会提示磁盘版本变化。再次保存前会检查磁盘内容，可以取消、重新载入磁盘版本，或明确选择覆盖。文件被外部删除也会要求确认。

也可以打开 [文件格式导览](格式示例/格式导览.md)，体验 SVG 的源码与图像预览切换，或修改使用自定义扩展名的文本文件。

示例工作区是应用在本机创建的可编辑副本，重新打开示例工作区会保留你的修改，并补入新版本新增的示例文件。
