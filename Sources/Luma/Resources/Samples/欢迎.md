# 把文件，读得清楚。

欢迎来到 **Luma · 澄览**，你的本地阅读空间。

这里是 **2026.11 蓝色主题示例集**：文档、图片和代码使用当前主题，完整格式导览收录 67 种格式或语言的代表文件。同格式的别名扩展名合并展示。

一份设计文档、一组实验数据，或一段刚写好的代码，都可以在同一个窗口里打开。文件保留在原来的位置，阅读从这里开始。

## 从一个文件夹开始

- 点击左上角的文件夹按钮，添加你正在使用的项目。
- 在侧栏选择文件；打开的文件会保留在标签页里。
- 将文件或文件夹拖进窗口，也可以直接打开。

> 源码模式可以编辑文本文件，按 ⌘S 才会保存到原文件。

## 换一种方式，看同一份内容

Markdown 可以在排版预览和源码之间切换，现在也支持表格、Mermaid 图表和代码语法高亮。JSON 以格式化代码显示，CSV 则会显示为表格。

[打开 Markdown 增强示例](Markdown增强预览.md)，看看表格、流程图、时序图和不同语言的代码块。

[打开图片与公式示例](图片与公式.md)，看看本地 PNG / SVG 图片，以及行内、独立显示的 LaTeX 公式。

[打开长文档导航示例](长文档导航.md)，试试目录折叠、章节跳转和随正文滚动的当前位置提示。

[打开正文搜索示例](正文搜索.md)，按 ⌘F 在预览中查找，试试匹配高亮和前后结果跳转。

正文默认居中排版。按 ⌘, 进入设置，可以调整最大宽度或铺满阅读区。悬停左侧短线可添加章节书签，按 ⌘D 可保存当前位置。阅读位置会自动记住，下次打开文档或重启应用时继续阅读。

设置里的「Markdown 阅读」还可以选择系统字体、宋体或等宽字体，调整 12–28pt 字号和 1.30–2.40 倍行距。修改即时生效并自动保存；调整排版时会尽量保持当前段落，代码和公式保留各自字体。

[打开源码编辑示例](源码编辑.md)，试试 Markdown、JSON、CSV 和代码的修改、预览与手动保存。

[打开完整文件格式导览](格式示例/格式导览.md)，查看每种格式的真实文件：独立 SVG、八类图片编码、JSON / JSONC / JSONL / NDJSON / GeoJSON、CSV / TSV、代码与配置，以及自定义扩展名文本。

## 留一点空间，给专注

1. 用 ⌘O 打开文件，⇧⌘O 添加文件夹。
2. 用 ⌘F 查找当前文本或 PDF。
3. 用 ⌘W 关闭当前标签，⌘R 重新载入文件。

---

**支持的文件**：Markdown、PDF、SVG、常见图片、JSON、CSV、TSV，以及 UTF-8 文本和代码。未知扩展名检测为文本后也可直接打开。
